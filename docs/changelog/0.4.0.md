# Pinote v0.4.0

本版本重新设计了侧边便签工作区, 重点改善 macOS 全屏 Space 中的展开, 切换和拖放体验, 同时修复 Markdown 预览和侧边任务交互问题.

## Highlights

- 侧边任务列表和活动便签现在共用一个固定侧边窗口, 点击任务只切换窗口内部内容, 不再依赖隐藏便签窗口跨 Space 重绑.
- 收纳便签后会销毁原独立窗口, 切换任务, 收回侧边栏, 同步, 退出和拖出前都会等待当前内容保存.
- 支持从任务列表或内嵌便签标题栏拖出独立窗口, 并处理窗口加载前移动, 提前释放和拖回侧边栏.
- 拖出过程中隐藏内嵌源便签, 避免重复内容形成残影.
- 侧边任务关闭增加两次点击确认, 确认状态会在超时或其他交互后清除.
- Markdown 预览会保留 fenced code 和普通标识符中的下划线.

## Upgrade Notes

- 无需迁移现有便签数据或同步配置.
