# Pinote v0.6.2

Date: 2026-09-19

本版本新增 local only 便签: 可以把任意便签设为仅保留在本机, 其后的修改不再上传同步服务器. 使用云同步的用户请先阅读 Upgrade Notes 再升级.

## Highlights

- 便签三点菜单新增 "仅保留在本机" 开关, 开启后的修改不再上传云端, 云端与其他设备上的既有副本保持原样.
- 仅本地便签的删除不再同步, 不会影响其他设备; 主窗口列表会用 "仅本地" 徽标标记这类便签.
- 重新选择 "恢复云同步" 后便签回到同步流程, 期间累积的修改自动补传, 与其他设备的改动冲突时按既有规则生成冲突副本.
- 新建便签后先开启 "仅保留在本机" 再填写内容, 这张便签从头到尾都不会向服务器发送任何数据.

## Features

- 便签: 三点菜单新增 "仅保留在本机" 与 "恢复云同步" 开关. 是否仅本地只影响当前设备, 该标记本身不参与同步; 删除确认框会针对仅本地便签提示删除不会影响云端和其他设备.
- 主窗口: 列表中的仅本地便签显示 "仅本地" 徽标.

## Upgrade Notes

1. 首次启动会自动把本地数据文件迁移到版本 11, 现有便签, 分组, tags, 窗口状态和同步配置全部保留, 无需手动处理.
2. "仅保留在本机" 是每台设备自己的决定, 想在其他设备上也停止同步某张便签, 需要在那台设备上单独开启.
3. 回退到 v0.6.1 或更早版本会丢失仅本地标记, 相关便签会恢复参与云同步, 便签内容本身不受影响.
