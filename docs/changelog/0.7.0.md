# Pinote v0.7.0

Date: 2026-11-26

本版本新增便签避让: 按住一个修饰键就能让挡在鼠标前面的便签让开, 松开后回到原位.

## Highlights

- 按住 `Command` (Windows 与 Linux 为 `Alt`) 时, 鼠标周围形成一片圆形立场, 与立场相交的便签会被推到立场边缘外, 松开按键后精确回到原位置.
- 鼠标追着便签移动时便签继续让开, 离开后自动滑回; 每次只移动刚好够让出立场的距离.
- 同一侧快速双击该修饰键切换 "保持避让", 不必一直按住; 再双击一次解除, 默认 30 秒内没有再次双击会自动取消.
- 设置 > 快捷键 > 便签避让 可以换用其他修饰键, 也能关闭保持避让的自动取消.
- 便签三点菜单改为系统原生菜单, 选项不再被便签窗口裁掉上半部分.

## Features

- 便签避让: 按住触发键时, 与圆形立场相交的便签让开到立场边缘外. 正在编辑的那张便签不参与, 正在拖动或调整大小的便签也不参与; 点击其他便签或让便签失去焦点后, 它会重新加入避让.
- 便签避让: 便签朝没有被菜单栏, 任务栏或 Dock 占据的一侧让开; 贴近屏幕边缘的大便签允许滑出屏幕一部分, 以便让出立场.
- 便签避让: 同一侧快速双击触发键进入保持避让, 左右两侧混按不算; 保持期间按住该键会临时取消避让, 松开后恢复, 再双击一次解除.
- 设置: 快捷键页新增 "便签避让" 分组, 可选择 `Command`, `Option`, `Control` 或 `Shift` 作为触发键, 并提供关闭保持避让自动取消的选项.

## Bug Fixes

- 便签: 快捷键, 撤销重做, 复制粘贴与全选作用于最后点击的那张便签, 不再落到之前聚焦的窗口.
- 便签: 点击便签后键盘输入直接进入便签, 不必再点一次编辑区.
- 便签: 拖动标题栏时产生的双击不再被当成收起或展开.
- 便签: 折叠便签相互重叠时用着色边框区分, 两端不再显示系统描边圆角; 标题区不再出现滚动条, 标题与正文之间留有间隔.
- 编辑器: 光标所在行的项目符号与编号保持渲染, 不再退回原始 Markdown 而让行内文字跳动.
- 编辑器: `Shift+Tab` 在任意缩进层级都能减少一层列表缩进, 并跳过代码块中的行; 列表缩进统一为 4 个空格.

## Upgrade Notes

1. macOS 上按住触发键若没有反应, 到 系统设置 > 隐私与安全性 > 输入监控 中允许 Pinote. 便签避让只读取修饰键状态, 不要求辅助功能权限.
2. 触发键默认是 `Command`, 如果与自己的操作习惯冲突, 可以在 设置 > 快捷键 > 便签避让 中换成其他修饰键.
