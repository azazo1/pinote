# Pinote v0.6.0

Date: 2026-09-11

本版本为桌面端补齐了托盘常驻, 单实例运行, 自动更新与日志排查能力, 并重做了打包与发布流程, 安装后可以直接在应用内升级.

## Highlights

- 关闭主窗口只隐藏到系统托盘, 应用继续在后台运行; 托盘菜单可以重新打开主窗口, 新建便签, 检查更新或退出.
- 同一数据目录只允许一个实例, 重复启动只会唤起已有窗口; 从终端启动时 `Ctrl+C` 会走和托盘退出相同的收尾流程, 先保存便签再退出.
- 内置自动更新: 启动 5 秒后静默检查一次, 也可以从托盘菜单, 应用菜单, 状态栏或设置的 "关于" 页手动检查, 下载后校验 `SHA256SUMS` 再按平台完成替换.
- 主窗口底部新增状态栏, 显示当前构建版本与同步状态, 发现新版本时可直接进入更新窗口.
- 新增日志设施, 日志写入数据目录的 `logs/pinote.log`, 按每日与单文件大小轮转, 设置中可以临时打开调试级别.

## Breaking Changes

- 打包入口统一为 `just dist`, 原有的 `just dist-mac`, `just dist-win`, `just dist-linux` 以及 `bun run dist:*` 脚本一并移除. 迁移方式: 在目标平台上执行 `just dist`, 由 recipe 按当前平台选择打包脚本, 不再需要手动指定架构.
- 归档命名和内容发生变化, 统一为 `<app>-<version>-<platform>-<arch>.<ext>`; Linux 与 Windows 归档的顶层是可直接运行的便携应用目录, 客户端整目录替换. 迁移方式: 重新从 GitHub Release 下载对应平台的归档.

## Upgrade Notes

1. 首次启动会自动把本地状态迁移到版本 10, 现有便签, 分组, tags, 窗口位置和同步配置都会保留, 无需手动处理.
2. 旧版本无法识别新增的设置项, 回退到 0.5.0 后托盘, 更新和日志相关设置会恢复默认值, 便签内容不受影响.
3. 自动更新失败时, 可以在更新窗口中重试, 或直接下载对应平台的归档手动替换.
4. 排查问题时打开设置中的 "记录详细日志", 复现后建议关闭, 日志文件路径显示在设置的 "关于" 页.

## Features

- 托盘与单实例: 新增托盘图标与托盘菜单, 关闭主窗口后仍可接收同步和更新; 同一数据目录只会保留一个实例.
- 自动更新: 检查, 下载, 校验与安装串成一条流程, 支持跳过某个版本; Linux 在进程内替换自身目录后重启, Windows 与 macOS 交给脱离进程的替换脚本, 应用退出后再完成目录或 `.app` 替换并重新拉起.
- 日志与诊断: 新增 `just debug` recipe, 以项目内的隔离数据目录和最高日志级别启动调试实例, 日志路径和级别可用 `PINOTE_LOG_FILE` 与 `PINOTE_LOG_LEVEL` 覆盖.
- 版本展示: 状态栏与 "关于" 页显示当前构建版本, tag 构建显示 `v0.6.0`, 非 tag 构建追加 7 位短 hash, 工作区有未提交改动时改用 `^` 分隔, 日常开发构建显示 `dev-build`.
- 打包与发布: 新增 `just dist` 与专供更新流程验证的 `just fake-dist`; CI 在 macOS, Windows, Linux 的 x86_64 与 aarch64 runner 上分别测试和打包, 并在发布时生成 `SHA256SUMS`.

## Bug Fixes

- 侧边栏: 折叠状态下的便签被收纳到侧边栏或拖入侧边栏时仍保持折叠, 现在会先展开再收纳.
